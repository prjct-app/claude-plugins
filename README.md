# prjct plugins for Claude Code

The `prjct` marketplace for [Claude Code](https://claude.com/claude-code), by [prjct](https://prjct.app).

```text
/plugin marketplace add prjct-app/claude-plugins
/plugin install palette@prjct
```

| Plugin | What it does |
| --- | --- |
| [palette](themes/) | Color themes for Claude Code: a picker with live preview, favorites, and your library from [palette.prjct.app](https://palette.prjct.app). The same palettes as pi-palette for Pi. |

Plugins with mods run code inside Claude Code with your permissions. Read a plugin before you install it: `claude plugin validate ./themes` lists every event it handles and every call it makes.
